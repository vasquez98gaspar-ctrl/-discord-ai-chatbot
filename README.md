# Discord AI Chatbot

A Discord bot built with Python and Discord APIs, focused on 
automated interactions, command handling, and AI-assisted workflow logic.

## Features
- Automated command handling
- AI-assisted responses
- Workflow automation logic

## Skills Used
- Python
- Discord API
- Automation Logic
- Debugging

## How to Run
1. Clone this repo
2. Install dependencies: `pip install discord.py`
3. Add your bot token
4. Run: `python discord_bot.py`
