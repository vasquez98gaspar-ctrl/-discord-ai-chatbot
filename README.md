# Discord AI Chatbot

A Discord bot built with Python and Discord APIs, focused on 
automated interactions, command handling, and AI-assisted workflow logic.

## Features
- Automated command handling
- Agentic AI responses: Claude can call bot tools itself (checking/issuing
  warnings, reading channel history) to satisfy a request in one turn,
  instead of being limited to a single fixed prompt-and-reply
- Per-channel conversation memory, so the bot has context across messages
- Workflow automation logic

## Skills Used
- Python
- Discord API
- Automation Logic
- Debugging

## How to Run
1. Clone this repo
2. Install dependencies: `pip install discord.py`
3. Add your bot token
4. Run: `python discord_bot.py`
